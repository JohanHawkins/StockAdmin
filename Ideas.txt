## Tecnologías

- **Frontend:** Angular 21 (SSR)
- **Backend:** Node.js + Express (integrado en Angular SSR)
- **Base de Datos:** PostgreSQL
- **Paquetes:** pg (node-postgres), dotenv

---

## Permisos por Rol

| Funcionalidad | Admin | Empleado |
|---------------|-------|---------|
| Dashboard | Solo lectura | Solo lectura |
| Productos | Crear, Editar, Eliminar, Activar/Desactivar | Solo lectura |
| Categorías | Crear, Editar, Eliminar | Solo lectura |
| Movimientos | Crear, Filtros | Crear, Filtros |

> Nota: el rol se aplica actualmente en la interfaz (botones ocultos). La API no verifica el rol por sí sola.

## Estado del Proyecto

### Completado (100%)

- Login con autenticación y roles
- Dashboard con estadísticas
- Productos (CRUD, búsqueda, paginación, estado)
- Categorías (CRUD, protección al eliminar)
- Movimientos (entradas/salidas, filtros, validación de stock)
- UI/UX (sidebar, modo oscuro, responsive, 404)
- Backend API REST con PostgreSQL
- Change detection corregido en todos los módulos
- Spinner de carga global al navegar
- Depuración de código: eliminados archivos, imports, métodos y CSS no utilizados
- Filtros avanzados de productos (categoría, estado, rango de precio, stock bajo, búsqueda por nombre/código)
- Exportar productos a CSV (respeta filtros y orden actuales, compatible con Excel)
- Importar productos desde CSV (validación por fila, omite duplicados, transacción en BD)
- Exportar historial de movimientos a CSV (respeta filtros aplicados)
- Auditoría y mejora de código:
  - Eliminados endpoints REST sin uso (GET /api/products/:code, GET /api/movements/:code, GET /api/auth/users)
  - Corregido generador automático de códigos P###/C### (fallaba con códigos importados no numéricos)
  - Login distingue credenciales incorrectas de errores de conexión
  - Dashboard carga en paralelo con forkJoin (sin spinner infinito ante errores)
  - Tipado del estado de producto ('Activo' | 'Inactivo') y eliminación de casts 'as any' en movimientos
- README profesional con capturas de pantalla
